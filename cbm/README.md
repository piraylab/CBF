# CBM

The bundled MATLAB functions implement the CBM fitting routines used by this repository. The repository's `setup` command adds this folder to the MATLAB path. CBM requires MATLAB and Optimization Toolbox.

Please cite Piray P, Dezfouli A, Heskes T, Frank MJ, and Daw ND (2019), “Hierarchical Bayesian inference for concurrent model fitting and comparison for group studies,” PLOS Computational Biology.
